# Backrooms: Streamer Survival — Launcher

Launcher oficial para entrar al servidor del evento. Descarga Minecraft, Fabric y
el modpack automaticamente: instala y dale a **Jugar**.

## Descargar

Ve a **[Releases](../../releases/latest)** y descarga `BackroomsLauncher-1.0.0-setup.exe` (Windows).

1. Instala (no pide permisos de administrador).
2. Abre el launcher, inicia sesion (Microsoft u offline) y pulsa **Jugar**.
3. El launcher baja todo (MC 1.20.1 + Fabric + mods) y te conecta al servidor.

## Que trae

- Minecraft **1.20.1** + Fabric Loader **0.15.11** + Java **17** (gestionado por el launcher).
- 16 mods del evento (el mod Backrooms + rendimiento + voz de proximidad).
- Servidor: `s12.mia.us.tarohosting.lat:33085`.

El `manifest.json` de este repo es lo que el launcher lee para saber que instalar.
